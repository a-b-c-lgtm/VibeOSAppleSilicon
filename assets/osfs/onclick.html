onclick handlers (chapter 111)

Each button below carries a real onclick="..." attribute. The pocketjs engine in userspace/libc/pocketjs.h evaluates the source on every click and the jsdom bridge in userspace/browser/jsdom.h mutates the live DOM / layout.

1. Hide the clicked element

Sets display:none on the button. Triggers relayout, so the paragraphs that follow flow up.

2. alert()

Latches the message in the page's alert buffer and mirrors it to the serial log. No modal yet.

3. document.getElementById + alert

Reads the input's value attribute, concats with a string literal, fires alert.
